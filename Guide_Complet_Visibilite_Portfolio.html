2. Google Search Console : Être premier sur Google

🔍 Vos informations dans Google Search Console

Votre site a été validé et indexé avec succès par Google. Vous pouvez y accéder à tout moment sur ordinateur à l'adresse : https://search.google.com/search-console/

Astuce mobile : Sur le navigateur Chrome de votre téléphone, ouvrez le lien ci-dessus, appuyez sur les 3 points (⋮) en haut à droite, puis sur « Ajouter à l'écran d'accueil » pour créer un raccourci direct.
📈 Ce qu'il faut surveiller chaque semaine
  • L'onglet Performances : vous indique le nombre total de clics et d'impressions (combien de fois votre nom ou portfolio est apparu sur Google).
  • Les Requêtes : la liste des mots-clés exacts saisis par les internautes pour vous trouver (ex: "Tchibkere Salomon", "Développeur Yaoundé").
  • L'état des Sitemaps : votre sitemap sitemap.xml est envoyé et guide les robots de Google régulièrement.
Que faire quand vous ajoutez un nouveau projet ?
Collez simplement l'URL de votre portfolio dans la barre supérieure de la Search Console et cliquez sur « DEMANDER UNE INDEXATION ». Google mettra à jour sa version sous 24h.

4. Comment mettre à jour votre site à l'avenir

💻 Les 3 commandes Git pour publier de nouveaux changements

Dès que vous modifiez un texte, ajoutez un projet ou mettez à jour votre code dans ce dossier, ouvrez un terminal et tapez :

git add .
git commit -m "Mise a jour de mon portfolio"
git push origin main

En 30 secondes, GitHub Pages publie automatiquement la nouvelle version sur Internet !
